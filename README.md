# WordChain

Arkadaşlarla sırayla oynanan, ücretsiz ve reklamsız online kelime zinciri oyunu. Kayıt yok, oda kurup linki paylaşmak yeterli.

- Çalıştırma: `npm install`, ardından `npm start` (http://localhost:3000)
- Yayınlama ve telefona ekleme: `KURULUM.md`
- Ortam değişkenleri: `PORT` (3000), `MIN_TURN_S` (en kısa düşünme süresi, 30), `START_DELAY_MS` (geri sayım, 3500)
- Lisanslar: `public/credits.txt`
