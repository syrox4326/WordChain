# WordChain

Arkadaşlarla oynanan, ücretsiz ve reklamsız online oyunlar: Kelime Zinciri (2-6 kişi) ve 20 TL Challenge (2 kişi). Kayıt yok, oda kurup linki paylaşmak yeterli.

- Çalıştırma: `npm install`, ardından `npm start` (http://localhost:3000)
- Yayınlama ve telefona ekleme: `KURULUM.md`
- Ortam değişkenleri: `PORT` (3000), `MIN_TURN_S` (Kelime Zinciri en kısa düşünme süresi, 30), `MIN_DECIDE_S` (20 TL Challenge en kısa karar süresi, 10), `SOLD_DELAY_MS` (satış ekranı süresi, 2600), `START_DELAY_MS` (geri sayım, 3500)
- Lisanslar: `public/credits.html`
